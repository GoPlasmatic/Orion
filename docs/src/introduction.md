# Orion documentation

Orion is a declarative services runtime. You define what a service does as a JSON workflow and expose it through a channel. Orion serves it with routing, guards, versioning and traces already in place.

<div class="hero-logo">
  <img src="images/plasmatic-logo.png" alt="Plasmatic logo">
  <p class="hero-sub">Post two JSON definitions, activate them, and the endpoint is live. No application server to write, build or restart.</p>
</div>

Orion is open source under Apache-2.0 and developed in the open at [GoPlasmatic/Orion](https://github.com/GoPlasmatic/Orion). Questions go to [Discussions](https://github.com/GoPlasmatic/Orion/discussions) and bugs to [Issues](https://github.com/GoPlasmatic/Orion/issues); the [versioning and support policy](./releases/versioning-policy.md) states what a release guarantees. If you use Orion, add yourself to [ADOPTERS.md](https://github.com/GoPlasmatic/Orion/blob/main/ADOPTERS.md): usage reports shape the roadmap.
