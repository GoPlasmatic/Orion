# `orion-cli functions`

`list` shows the workflow task functions registered in the engine and their input schemas. Alias: `fn`. The catalog is documented in [Task Functions](../../functions/index.md).

## Synopsis

```bash
orion-cli functions list
```

## Examples

```bash
orion-cli functions list
```
