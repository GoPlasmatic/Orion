# `orion-cli completions`

Generates shell completions for `bash`, `zsh`, `fish`, `powershell`, or `elvish`. Alias: `comp`.

## Synopsis

```bash
orion-cli completions <bash|zsh|fish|powershell|elvish>
```

## Examples

```bash
orion-cli completions zsh > ~/.zfunc/_orion-cli
```
